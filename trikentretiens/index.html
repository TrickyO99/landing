One offer in, one tailored CV out. It reads the job description, picks what matters from my real experience, and lays out a one-page CV and a cover letter for that role.

See the base CV 30+ offers tailored
  1. 1. Read the offer

    Role, stack, tone, language. The CV follows the language of the offer.

  2. 2. Pick the facts

    Everything comes from one source CV. Nothing gets invented, only reordered and reworded.

  3. 3. Build the page

    One A4 page, rendered to PDF, plus a short cover letter in the same folder.

  4. 4. Track it

    Each application and its status goes into a tracker, so nothing gets lost.

House rules

  • No skill on the CV that is not really mine.
  • One page, always.
  • Each offer gets its own folder: CV, letter, source offer.

Use it yourself

The tool behind this page is open. Give it your CV once, then one offer at a time. You get a one-page CV, a cover letter, and a list of what the offer wants that you can't show.

pip install .
resume-tailor init my-cv.pdf
resume-tailor tailor offer.txt
  • It checks every number, tool and year count against your own profile, and flags what you can't back up.
  • It runs on your machine with your own Anthropic API key. Only your profile and the offer text go to the API.
  • Needs Python 3.10+ and Chrome, Chromium or Edge to print the PDFs. MIT licence.

Where the offers come from: igaming-jobs-fr

A companion project for the job hunt. It gathers the openings of the online gambling operators licensed by the ANJ (the French regulator) in one searchable French-language board, so there is no need to visit each careers site by hand.

  • Sources. 14 ANJ-licensed operators are listed. 8 are scraped today: bwin/partypoker (Entain), PMU, Betsson, Winamax, FDJ United, PokerStars (Flutter), Betclic and bet365. The other 6 (Circus, NetBet, Vbet, Genybet, Olybet, Feelingbet) are shown as "not monitored", so the gaps stay visible.
  • How it reads them. One small adapter per source: public APIs where they exist (SmartRecruiters, Workday, a WordPress AJAX endpoint), Welcome to the Jungle pages for the others, and a headless browser only when nothing else works. Requests are rate-limited and retried politely.
  • What it stores. Title, location and country, contract type, description and a category worked out from the title (Support, Tech / Data, Marketing, Legal, Finance and so on). Each run marks offers that disappeared as inactive instead of deleting them.
  • Last run (September 2026). 611 active offers across the operators, about 40% in customer support and 26% in tech and data.
  • The site. Next.js with a local SQLite file. Filterable list, one page per offer with JobPosting structured data, sitemap and robots.txt. A scrape runs once or in a loop with npm run scrape and npm run scrape:loop.

Status: built and working locally, not deployed yet. It has no public domain, so there is no link to open.
